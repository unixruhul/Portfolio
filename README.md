MD RUHUL AMIN — PORTFOLIO PROJECT

Files:
- index.html: single-page responsive portfolio (About Me, Skills, Project Details, Recommendations)
- style.css: responsive layout, visual styling and hover effects
- script.js: recommendation submission and success popup (showPopup is called only after a new card is appended)
- assets/profile.svg: original illustrated profile avatar
- functionality.png: portfolio overview screenshot
- new_recommendation.png: screenshot showing the added recommendation and confirmation

How to run:
1. Keep the folder structure unchanged.
2. Open index.html in a modern browser.
3. Use the recommendation form to add a recommendation. The page updates immediately; no backend is required.

Note: Recommendation quotes are illustrative portfolio examples, not attributed to named real referees. Replace them with genuine approved references before publishing.
